# App policies

Pages publiques de confidentialité des applications de benahm.

## Applications

- [SillyJo](https://benahm.github.io/app-policies/sillyjo/privacy/)

## Ajouter une application

Créer un dossier `<application>/privacy/index.html`, puis ajouter son lien à `index.html` et à cette liste.

## Publication

GitHub Pages publie la racine de la branche `main`. Les changements poussés sur cette branche sont publiés automatiquement.

Ce dépôt contient uniquement des documents publics, sans code source des applications.
